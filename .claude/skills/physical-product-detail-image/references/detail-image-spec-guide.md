# 상품 상세 이미지 생성 명세 가이드

## 목적과 경로

제품 정체성, 확정 상품 정보, 촬영 소스, 패널 콘텐츠, 조판 원본과 실제 출력 결과를
추적한다.

- 명세: `docs/image-generation/{product-slug}/detail-image-spec.md`
- 조판 원본: `docs/image-generation/{product-slug}/detail-page-source/`
- 촬영 소스: `public/images/products/{product-slug}/detail-page/sources/`
- 최종 패널: `public/images/products/{product-slug}/detail-page/panels/`

사용자가 다른 경로를 정하면 그 경로를 기록한다.

## 작성 규칙

- 미정은 `미정`, 해당하지 않으면 `해당 없음`으로 기록한다.
- 사용자 제공 사실, 이미지에서 확인한 시각 사실, 미확정 정보를 구분한다.
- 생성 전에는 예정 경로, 생성 후에는 실제 경로·크기·형식을 기록한다.
- 프롬프트는 실제 이미지 도구에 전달한 원문만 기록한다.
- 확인할 수 없는 모델명, 시드, 설정과 상품 정보를 추정하지 않는다.
- 기존 촬영 소스를 재사용하면 원본 경로와 재사용 판단 근거를 기록한다.
- 명세에 자체 품질 점수나 근거 없는 합격 판정을 쓰지 않는다.
