# 상품 상세 이미지 패널 제작 기준

## 목표

상품 상세 이미지는 사진 갤러리가 아니라 `상품정보 더보기` 영역에서 순서대로 이어지는
구매 설득 콘텐츠다. 제품 사진과 사실에 근거한 정보를 결합해 작은 화면에서도 빠르게
이해할 수 있어야 한다.

## 패널 구성

### `01-hero` — 핵심 소개

- 정식 상품명
- 확인된 한 문장의 핵심 가치
- 대표 제품 사진
- 상품과 어울리되 절제된 배경

### `02-benefits` — 주요 장점

- 구매 이유가 되는 장점 최대 3개
- 짧은 제목과 한두 줄 설명
- 각 장점을 실제로 뒷받침하는 사진 또는 사실

근거가 없는 장점을 수를 맞추기 위해 만들지 않는다.

### `03-components` — 구성품

- 실제 포함 구성품의 명칭과 정확한 수량
- 서로 겹쳐 수량을 오해하지 않도록 한 배치
- 포함되지 않는 연출 소품과 명확한 구분

### `04-material` — 소재와 마감

- 소재·구조·마감의 근접 이미지
- 판매 사양에 근거한 소재와 제작 설명
- 보이는 외관만으로 추정한 재료나 공법 금지

### `05-size` — 크기와 규격

- 상품에 필요한 가로·세로·높이·중량·수량·용량
- 법정 계량 단위
- 실제 측정값이나 확정 사양만 사용

측정값이 없으면 임의 숫자나 시각적 치수선을 만들지 않는다.

### `06-usage` — 사용 방법

- 실제 사용 순서 또는 배치 방법
- 단계가 있으면 1, 2, 3 순서
- 사람이 꼭 필요하지 않으면 제품 중심으로 설명

### `07-notice` — 관리 및 구매 안내

- 보관·세척·취급·안전 주의사항
- 식품의 소비기한·알레르기·보관 조건 등 적용 정보
- 배송 중 발생 가능한 변화와 교환·반품 조건
- 이미지 밖에서도 제공해야 할 법적 고지와 정책 정보 식별

## 공통 아트 디렉션

- 세련되고 절제된 한국 웨딩 편집숍
- 아이보리와 따뜻한 뉴트럴 기반
- 부드러운 측면 자연광과 현실적인 그림자
- 작은 화면에서도 분명한 정보 위계
- 장식보다 제품 정보와 구매 판단 우선
- 상품별 보조색은 승인된 기준 이미지와 일치
- 과도한 꽃, 보케, 장식 프레임과 근거 없는 감성 문구 배제
- 사실과 다른 기능·인증·원산지·소재·수치 금지

## 조판 규칙

- 기준 폭은 860px이다.
- 각 패널 높이는 정보량에 따라 정하고 단일 비율로 맞추지 않는다.
- 패널 전체에 같은 배경색, 서체, 여백, 컬러 토큰을 사용한다.
- 사진 위에 긴 본문을 직접 겹치지 않는다. 대비와 가독성을 우선한다.
- 제목, 본문, 보조 문구, 수치 사이의 단계가 시각적으로 구분되어야 한다.
- 장식 요소는 구성품처럼 보이지 않게 배치하거나 명시적으로 구분한다.
- 패널을 세로로 연결했을 때 갑작스러운 배경 변화나 중복 여백이 생기지 않게 한다.
- WebP 변환 전 편집 가능한 조판 원본 또는 무손실 원본을 보존한다.

## 촬영 소스 공통 조건

승인된 기준 이미지를 제품 정체성 참조로 사용한다. 변경할 수 있는 것은 필요한 촬영
시점과 배치뿐이다.

- 실제 제조 가능한 구조와 자연스러운 접촉·중력
- 완전한 판매 구성, 소재 근접, 사용 방식의 세 역할
- 조판을 위한 실용적인 주변 여백
- 같은 웜 뉴트럴 색감과 부드러운 측면광
- 구성품의 분리와 정확한 수량
- 사람·손·생활 공간은 상품 설명에 꼭 필요할 때만 사용
- 문장, 규격, 로고, 브랜드명, 라벨, 워터마크와 생성 문자 금지
- 중복·융합·기형·부유·과도한 반사·차가운 조명·과도한 보케·일러스트·3D 렌더 인상 금지

## 출력 검수

- 7개 패널의 번호와 역할이 파일명과 일치한다.
- 모든 패널 폭이 860px이며 세로 비율은 내용에 맞다.
- 패널을 모바일 표시 폭으로 축소해도 핵심 본문과 수치를 읽을 수 있다.
- 압축으로 작은 글자, 얇은 선, 제품 재질이 깨지지 않는다.
- 패널을 순서대로 이어 붙여 배경과 여백의 연결을 육안으로 확인한다.
