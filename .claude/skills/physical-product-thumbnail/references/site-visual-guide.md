# Tie Knot 물리 상품 썸네일 사이트 시각 기준

## 목적과 갱신 조건

물리 상품 썸네일을 현재 쇼핑몰 UI에 일관되게 배치하기 위한 정적 기준이다. 이미지
생성마다 사이트를 다시 분석하지 않는다. 아래 근거 파일에서 이미지 비율, 오버레이,
테마 토큰 또는 재사용 방식이 바뀌었을 때 이 문서를 갱신한다.

확인 기준일: 2026-09-16

## 근거 파일

| 역할 | 경로 | 확인할 값 |
|---|---|---|
| 상품 목록 카드 | `src/ui/components/molecules/ProductCard/ProductCard.tsx` | `1:1.618`, 상단 배지, 하단 정보·그라데이션, 확대 |
| 이미지 표시 | `src/ui/components/atoms/app-image.tsx` | `object-cover`, `fill`, `group-hover:scale-[1.06]` |
| 상품 상세 대표 이미지 | `src/app/(main)/(products)/products/[category]/[id]/_components/ProductSummary.tsx` | 정사각형 표시, 상단 배지, 확대 |
| 주문 내역 | `src/app/(main)/(my-order)/my-orders/_containers/OrderCard.tsx` | `96 × 96px` 정사각형 축소 표시 |
| 결제 요약 | `src/app/(main)/(checkout)/_components/OrderSummary.tsx` | `80 × 96px` 축소 표시 |
| 쇼핑몰 색상 | `src/app/globals.css`의 `:root` | 기본 쇼핑몰 색상 토큰 |

청첩장 미리보기의 `[data-theme]` 값은 청첩장 상품 내부 테마다. 쇼핑몰 상품 카드의
배경 기준으로 사용하지 않는다.

## 쇼핑몰 시각 언어

| 항목 | 현재 값 | 생성 적용 |
|---|---|---|
| 화면 배경 | `#faf6f1` | 차갑고 푸른 흰색보다 따뜻한 중성색과 조화시킨다 |
| 기본 글자 | `#3a342e` | 상품 윤곽이 이 색과 함께 놓여도 탁해지지 않게 분리한다 |
| 주요 강조색 | `#aa6147` | 테라코타 계열과 충돌하는 고채도 주황·적색을 남용하지 않는다 |
| muted | `#efe7dc` | 밝은 배경은 muted보다 상품 경계가 분명해야 한다 |
| accent | `#e8ddd0` | 웜 베이지·아이보리 계열을 기본 조화 범위로 삼는다 |
| 카드 형태 | 모서리 `rounded-2xl` | 중요한 형태를 모서리에 걸치지 않는다 |

전반 인상은 따뜻하고 차분한 웨딩 이커머스다. 상품 고유 색이 우선이며, 배경과 소품은
사이트 색을 그대로 복제하기보다 이 온도와 채도 범위 안에서 보조한다.

## 출력과 재사용 조건

| 사용처 | 표시 방식 | 생성 시 대응 |
|---|---|---|
| 상품 목록·홈 인기 상품 | 세로형 `1:1.618`, `object-cover` | 최종 캔버스 기준. 상단과 하단 UI를 피한다 |
| 상품 상세 | 중앙 정사각형 잘림 | 핵심 형태와 특징을 중앙 정사각형에도 남긴다 |
| 주문 내역 | `96 × 96px` 정사각형 | 축소해도 종류를 구분할 실루엣과 대비를 만든다 |
| 결제 요약 | `80 × 96px` | 작은 세로 썸네일에서도 주 상품이 소품과 분리돼야 한다 |

- 최종 비율: 너비 1 : 높이 1.618
- 기본 출력: `1200 × 1942px` WebP. 생성 도구가 정확한 크기를 지원하지 않으면 더
  큰 세로 이미지를 생성한 뒤 안전 영역을 유지하며 중앙 자르기·크기 조정한다.
- 기준 이미지: 지원되는 가장 큰 정사각형 PNG. 실제 크기를 생성 명세에 기록한다.
- 최종 이미지 위 상품명·가격·할인·홍보 문구: 없음

## 안전 영역

좌상단을 원점으로 한 백분율 좌표 `(x, y, 너비, 높이)`를 사용한다. 다음 값은 현재
컴포넌트 배치를 이미지 생성에 적용하기 위한 고정 작업 기준이다.

| 영역 | 좌표 | 규칙 |
|---|---|---|
| 상품 핵심 특징 | `(15, 20, 70, 45)` | 로고·각인·형태의 결정적 부분을 둔다 |
| 상품 전체 실루엣 | `(8, 14, 84, 66)` | 확대와 둥근 모서리 뒤에도 전체 인지가 가능해야 한다 |
| 상단 UI 회피 | `(0, 0, 100, 18)` | 순위·추천·프리미엄·할인 배지가 올 수 있다 |
| 하단 UI 회피 | `(0, 65, 100, 35)` | 검은 그라데이션과 상품명·가격·좋아요가 항상 표시된다 |
| 중앙 정사각형 잘림 | `(0, 19.1, 100, 61.8)` | 상세·주문 화면에서 남아야 할 영역이다 |
| 확대 여유 | 바깥쪽 각 4% | `1.06` 확대에서 핵심 형태가 잘리지 않게 비운다 |

상품 전체가 하단 회피 영역과 일부 겹칠 수는 있지만, 핵심 특징·작은 구성품·표면
문자는 그 영역에 두지 않는다. 세트 상품은 모든 구성품을 억지로 핵심 영역에 넣기보다
대표 상품을 중심에 두고 나머지는 판매 구성임을 읽을 수 있는 크기로 배치한다.

## 갱신 확인 목록

다음 중 하나가 바뀌면 코드와 실제 화면을 확인해 이 문서를 갱신한다.

- `ProductCard`의 비율, 배지 위치, 하단 정보 높이 또는 그라데이션
- `AppImage`의 `object-fit` 또는 확대 배율
- 상품 상세·주문·결제 화면의 썸네일 비율
- `:root` 쇼핑몰 색상 토큰
