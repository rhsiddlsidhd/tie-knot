# Tie Knot 물리 상품 공통 촬영 기준

## 적용 원칙

이 문서는 모든 물리 상품 썸네일이 공유할 촬영 언어를 정한다. 색감·밝기·여백·상품
우선순위는 공통으로 유지하고, 재질·형태에 따라 광원 방향, 촬영 각도, 반사 제어와
심도를 조정한다.

상품 고유 색과 사용자가 승인한 외형이 이 문서보다 우선한다. 공통 기준 때문에 상품
색, 구성품, 재질 또는 포장 상태를 바꾸지 않는다.

## 공통 기준

| 항목 | 기본 기준 | 허용 조정 |
|---|---|---|
| 전체 인상 | 따뜻하고 차분한 웨딩 에디토리얼, 정돈된 상업 사진 | 상품 가격대·용도에 맞춰 친근함 또는 고급감 조정 |
| 노출 | 밝은 중간톤, 흰색과 밝은 재질의 디테일 보존 | 어두운 상품은 윤곽 분리를 위해 배경 밝기 조정 |
| 색온도 | 중성에서 약한 웜톤, 대략 `4800–5600K` 인상 | 제품 고유 색이 변해 보이면 중성에 가깝게 조정 |
| 채도 | 절제된 자연 채도 | 상품의 핵심 색만 선택적으로 강조 |
| 대비 | 부드러운 중간 대비 | 투명·저대비 상품은 윤곽을 위해 국소 대비 강화 |
| 주 광원 | 크고 부드러운 확산광 하나를 기본 | 금속·유리·각인 표현에 스트립광·림라이트 추가 가능 |
| 그림자 | 접촉감이 있고 경계가 부드러운 짧은 그림자 | 상품 높이와 연출 콘셉트에 따라 방향·길이 조정 |
| 배경 | 따뜻한 아이보리·웜 베이지·저채도 중성색 우선 | 상품과 명도 대비가 부족하면 저채도 보색 또는 짙은 중성색 허용 |
| 상품 점유율 | 실루엣은 크고 명확하게, 화면 가장자리에는 여유 유지 | 세트 구성은 대표 상품 우선으로 점유율 배분 |
| 선명도 | 상품과 핵심 특징은 선명하고 재질 질감이 보임 | 배경·보조 소품만 완만하게 흐릴 수 있음 |
| 보정 | 깨끗한 상업 사진 수준, 과도한 HDR·샤픈·블룸 금지 | 재질 표현에 필요한 국소 보정만 허용 |

## 재질별 조정

| 재질 | 광원·반사 | 주의점 |
|---|---|---|
| 종이·목재 | 넓은 측면광으로 결·두께 표현 | 누렇게 뜨거나 표면이 평면처럼 사라지지 않게 한다 |
| 패브릭 | 사선 측광으로 직조·주름을 부드럽게 표현 | 깊은 주름이 오염이나 손상처럼 보이지 않게 한다 |
| 유리·투명 소재 | 큰 확산광과 가장자리 하이라이트로 윤곽 분리 | 배경이 상품을 관통해 형태가 사라지지 않게 한다 |
| 유광 금속 | 반사판 형태가 정돈된 긴 하이라이트 | 카메라·사람·무관한 공간의 반사를 만들지 않는다 |
| 무광 세라믹·석재 | 넓은 광원과 약한 측면 대비 | 표면을 플라스틱처럼 번들거리게 만들지 않는다 |
| 액체·왁스 | 표면 높이와 투명도·점도를 읽을 수 있는 각도 | 내용물의 양·색을 승인 명세와 다르게 만들지 않는다 |

## 배경과 소품

- 배경은 상품을 설명하는 무대이며 주제가 아니다. 복잡한 실내 장면보다 단색,
  미세한 종이·패브릭·석재 질감, 단순한 면 분할을 우선한다.
- 소품은 받침대, 천, 꽃·식물 일부, 리본, 종이 오브제처럼 결혼·선물 맥락을 보조하는
  범위에서 사용한다.
- 소품은 원칙적으로 0–3종으로 제한하고, 어느 것도 주 상품보다 크거나 선명하거나
  채도가 높지 않게 한다.
- 판매 구성품과 연출 소품은 간격, 높이, 재질 또는 배치로 명확히 구분한다. 리본·꽃을
  실제 포함 구성품처럼 상품에 결합하지 않는다.
- 사용자가 제공하지 않은 음식, 원재료, 효능을 암시하는 소품으로 상품 속성을
  만들어내지 않는다.

## 구도와 식별성

- 작은 카드에서 상품 종류를 먼저 읽을 수 있는 실루엣을 만든다.
- 주 상품과 배경 사이에 명도 또는 색상 대비를 확보한다.
- 긴 상품은 대각선으로 눕혀 억지로 채우기보다 세로성을 살리고, 낮고 넓은 상품은
  탑뷰 또는 높은 사선 각도를 검토한다.
- 세트는 대표 상품 하나를 시선 중심으로 두고, 포함 구성품은 수량과 관계를 읽을 수
  있게 배치한다.
- 정사각형 잘림과 작은 축소에서도 핵심 특징이 남는지 연출안을 작성할 때 확인한다.

## 금지 표현

- 존재하지 않는 브랜드, 로고, 라벨, 인증 마크, 읽을 수 없는 장식 문자
- 상품 수량·크기·포장·구성품을 승인 명세와 다르게 보이게 하는 연출
- 공중에 뜬 상품, 접촉 그림자 누락, 잘못된 반사처럼 물리적으로 모순된 표현
- 상품보다 강한 소품, 과도한 꽃 장식, 웨딩 클리셰의 무분별한 반복
- 과도한 렌즈 왜곡, 얕은 심도로 핵심 특징이 흐려지는 표현
- 사이트의 따뜻한 저채도 환경과 충돌하는 형광색 배경과 강한 컬러 캐스트
