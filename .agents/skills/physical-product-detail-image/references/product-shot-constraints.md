# 기존 상품별 촬영 제약

대상 상품과 승인된 기준 이미지가 아래 항목과 일치할 때만 적용한다. 경로와 파일명은
실제 저장소에서 확인하고, 없는 파일을 생성 완료 상태로 간주하지 않는다.

## 수제 쿠키 답례품

- 기준 이미지 후보: `favor/return-gift-02-diagonal-open.webp`
- 유지: 아이보리 선물 상자, 캐러멜 브라운 리본, 버터 쿠키 구성
- 촬영: 열린 전체 상자, 쿠키 질감과 칸막이 근접, 상자 옆 쿠키 정확히 1개
- 금지: 중복·융합·용해·파손되거나 부자연스러운 쿠키
- 필요한 사실: 구성 수량, 개별 포장, 중량, 원재료, 알레르기, 소비기한, 보관 방법

## 진주 헤어핀 세트

- 기준 이미지 후보: `accessory/wedding-accessory-01-fan.webp`
- 유지: 크기가 다른 진주 헤어핀 정확히 3개, 골드 톤 핀, 펄 핑크 받침
- 촬영: 3개 전체, 진주와 와이어 연결 근접, 머리·사람·마네킹 없는 연출
- 금지: 핀 추가·누락, 떠 있는 진주, 기형 진주, 휜 금속, 융합된 장식
- 필요한 사실: 핀별 크기, 소재, 도금, 진주 종류, 중량, 보관 방법, 알레르기 주의

## 패브릭 웨딩 방명록

- 기준 이미지 후보: `guestbook/guestbook-01-closed.webp`
- 유지: 웜 아이보리 패브릭 표지, 웜 그레이 책등, 금속 펜 정확히 1개
- 촬영: 닫힌 전체 세트, 패브릭과 제본 근접, 두꺼운 무지 내지가 보이는 반개방 상태
- 금지: 인쇄 문구, 줄 내지, 잘못된 제본, 펜 중복, 얇은 노트 형태
- 필요한 사실: 전체 크기, 내지 수와 평량, 내지 형태, 제본, 표지 소재, 펜 포함 여부

## 혼인서약서·성혼선언문 케이스

- 기준 이미지 후보: `ceremony/ceremony-supply-02-three-quarter.webp`
- 유지: 샴페인 골드 테두리와 리본이 있는 웜 아이보리 리넨 케이스 정확히 2개
- 촬영: 닫힌 케이스 2개, 리넨과 테두리 마감, 케이스 하나를 펼치고 모서리 리본에
  고정한 무지 예식 용지 정확히 2장
- 금지: 책등, 제본된 종이 뭉치, 인쇄 문구, 액자, 사무용 폴더, 추가 케이스
- 필요한 사실: 케이스 2개 구성, 대응 용지, 외부 크기, 소재, 문서 고정, 인쇄 포함 여부

## 화동 바구니

- 기준 이미지 후보: `ceremony/flower-girl-basket-03-elevated.webp`

  절제된 아이보리·블러시 꽃잎
- 촬영: 전체 바구니, 직조 섬유와 손잡이 연결 근접, 안감과 꽃잎이 보이는 높은 시점
- 금지: 추가 바구니, 과도한 꽃, 부케 연출, 피크닉 바구니 인상, 기형 직조
- 필요한 사실: 외부·내부 크기, 손잡이 포함 높이, 소재, 꽃잎 포함 여부와 권장 사용량
