# 물리 상품 썸네일 생성 명세 작성 가이드

## 목적과 범위

승인된 상품 외형·연출·적용 기준과 생성 산출물을 구조화해 기록한다.
별도 검수 에이전트가 기대 조건과 실제 이미지를 비교할 때 사용하는 입력 문서다.
이 명세에는 검수 결과·점수·합격 판정·자체 평가를 작성하지 않는다.

## 작성 시점과 저장 위치

- 상품 외형 제안 시 명세를 시작하고, 사용자 승인·연출 선택·생성·수정 후 갱신한다.
- 명세: `docs/image-generation/{product-slug}/generation-spec.md`
- 기준 이미지: `public/images/products/{product-slug}/thumbnail/reference.png`
- 최종 썸네일: `public/images/products/{product-slug}/thumbnail/thumbnail.webp`
- 이미지를 만들기 전에는 예정 경로로 기록하고, 생성 후 실제 경로·형식·크기를 기록한다.

## 작성 규칙

- 아래 Markdown 템플릿의 항목명과 순서를 유지한다.
- 미정은 `미정`, 해당하지 않는 항목은 `해당 없음`으로 기록한다. 빈칸을 남기지 않는다.
- 사용자 제공 정보와 스킬 제안을 구분한다. 제안을 승인된 사실로 기록하지 않는다.
- 승인은 대화에서 확인한 범위만 기록한다. 파일 생성 완료는 사용자 승인이나 검수 통과를 의미하지 않는다.
- 상품 설명과 기준 이미지는 생성할 상품의 정의다. 실제 판매 상품의 실측·촬영 증거로 표현하지 않는다.
- 사이트 분석은 매번 반복하지 않는다. 스킬 내부에 저장된 사이트·촬영 기준을 참조한다.
- 참조 문서는 경로·버전 또는 확인 가능한 식별값과 이번 생성에 적용한 조건을 기록한다.
- 기준 문서가 없거나 적용값이 미정이면 그 상태를 명시한다. 승인된 기준을 임의로 만들지 않는다.
- 14개 연출 요소를 모두 기록한다. 공통 기준을 유지하는 부분과 상품 특성 때문에 조정하는 부분을 구분한다.
- 안전 영역은 이미지 좌상단을 원점으로 한 백분율 좌표 `(x, y, 너비, 높이)`로 기록한다.
- 상품 외형은 기준 이미지로 참조하고, 수정 시 요청받은 요소 외의 외형·연출 조건은 유지한다.
- 생성 도구에 전달한 프롬프트와 참조 이미지 경로를 기록한다. 지원되지 않거나 확인할 수 없는 모델·시드·설정값은 추정하지 않는다.

## 명세 템플릿

아래 코드 블록을 상품별 명세 파일에 복사한다. 중괄호는 실제 값으로 대체한다.

```markdown
# {상품명} 썸네일 생성 명세

## 1. 기본 정보

| 항목 | 값 |
|---|---|
| 상품 식별자 | {product-slug} |
| 상품 유형·상품군 | 물리 상품 / {상품군} |
| 명세 버전·작성일 | {버전} / {작성일} |
| 진행 단계 | {외형 제안 / 외형 승인 / 연출 제안 / 연출 승인 / 생성 완료 / 수정 완료} |
| 사용자 요청 | {상품 및 제작 목적} |

## 2. 적용 기준

| 자료 | 경로·식별값 | 이번 생성에 적용할 조건 |
|---|---|---|
| 사이트 시각 기준 | {경로·버전} | {색상·노출 화면·이미지 표시 방식} |
| 공통 촬영 기준 | {경로·버전} | {색감·여백·공통 연출 규칙} |
| 연출 요소 참고 문서 | {경로·버전} | {선택에 사용한 기준} |
| 시각 참고 자료 | {경로 또는 출처} | {참고할 부분과 제외할 부분} |

## 3. 상품 외형

| 항목 | 명세 | 출처·확정 상태 |
|---|---|---|
| 종류·용도 | {내용} | {사용자 제공 / 스킬 제안, 미승인 / 승인} |
| 형태·비율 | {내용} | {출처·상태} |

| 색상 | {내용} | {출처·상태} |

| 판매 단위·구성품 | {단품·세트 및 포함 품목} | {출처·상태} |
| 포장·개봉 상태 | {내용} | {출처·상태} |
| 브랜드·로고·라벨 | {사용자가 제공한 자산·정확한 문구 또는 없음} | {출처·상태} |
| 강조할 특징 | {썸네일에서 보여줄 특징} | {출처·상태} |
| 유지할 외형 | {연출·수정 중 변경하지 않을 부분} | {출처·상태} |

기준 이미지: {예정 또는 실제 경로}
외형 승인: {대화에서 확인한 승인 내용 또는 미승인}

## 4. 연출안 선택

| 안 | 콘셉트 | 주요 연출 차이 | 선택 상태 |
|---|---|---|---|
| A | {콘셉트} | {차이} | {선택 / 미선택 / 미정} |
```
