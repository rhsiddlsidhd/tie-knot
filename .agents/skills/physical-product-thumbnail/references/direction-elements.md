# 물리 상품 썸네일 연출 요소

## 사용 방법

승인된 상품 외형을 기준으로 아래 14개 요소를 모두 검토한다. 각 연출안은 요소별
선택지를 따로 나열한 설문이 아니라, 하나의 목적과 인상으로 결합된 완성안이어야 한다.
공통 촬영 기준을 유지하는 값과 상품 특성 때문에 조정하는 값을 구분해 생성 명세에
기록한다.

## 14개 요소

| 요소 | 결정할 내용 | 검토 질문 |
|---|---|---|
| 광원 | 방향, 크기, 강도, 색온도, 자연광·스튜디오광 | 어떤 빛이 형태와 재질을 가장 정확히 보여주는가? |
| 그림자 | 방향, 길이, 농도, 경계, 접촉감 | 상품이 바닥에 놓인 위치와 무게가 자연스러운가? |
| 배경 | 색상, 명도, 질감, 공간 깊이 | 사이트 색과 조화되면서 상품 윤곽이 분리되는가? |
| 배치 | 위치, 방향, 개수, 정렬, 겹침 | 판매 단위와 구성품 관계가 오해 없이 읽히는가? |
| 구도 | 점유율, 여백, 시선 흐름, 잘림 | 세로 카드와 정사각형 잘림에서 핵심이 남는가? |
| 촬영 각도 | 정면, 측면, 사선, 탑뷰, 카메라 높이 | 용도와 가장 중요한 면을 한눈에 설명하는가? |
| 원근감 | 촬영 거리, 화각, 형태 왜곡, 공간 압축 | 실제 비율과 크기 관계가 왜곡되지 않는가? |
| 초점·심도 | 선명 영역, 배경 흐림, 초점 전이 | 핵심 특징과 구성품이 필요한 만큼 선명한가? |
| 재질 표현 | 표면 결, 투명도, 두께, 유연성 | 승인된 재질이 다른 소재처럼 보이지 않는가? |
| 반사·하이라이트 | 위치, 길이, 강도, 광택 | 윤곽과 재질을 설명하며 결함처럼 보이지 않는가? |
| 색채 설계 | 배경 조화, 명도·채도 대비, 강조색 | 상품 고유 색을 보존하고 사이트와 충돌하지 않는가? |
| 소품·받침대 | 품목, 수량, 크기, 위치, 시각적 비중 | 판매 구성품과 구분되며 상품보다 약한가? |
| 상품 상태 | 포장·개봉·조립, 내용물·구성품 노출 | 실제 판매 상태와 사용자가 강조하려는 내용을 반영하는가? |
| 보정·마감 | 노출, 화이트밸런스, 대비, 채도, 선명도, 노이즈 | 깨끗한 상업 이미지이면서 질감과 색을 과장하지 않는가? |

## 연출안 차별화 기준

세 안은 사용자가 의미 있는 선택을 할 수 있도록 다음 중 두 가지 이상에서 분명한
차이를 만든다.

- 사용 맥락: 스튜디오 제품 사진, 선물 장면, 절제된 생활 공간
- 시선: 정면 중심, 높은 사선, 탑뷰
- 배경 구조: 단색, 질감 면, 받침대·면 분할
- 광원 성격: 균일한 확산광, 창가 인상, 방향성 있는 에디토리얼 광원
- 배치: 상품 단독, 판매 구성 중심, 제한된 소품과 함께

상품 외형, 판매 수량, 제공된 로고·라벨, 공통 안전 영역은 세 안에서 바꾸지 않는다.

## 연출안 출력 형식

각 안을 다음 구조로 제시한다.

```markdown
### A. {콘셉트명}

의도: {상품 특징과 전달할 인상}
핵심 차이: {다른 안과 비교되는 연출 결정}

| 요소 | 적용값 | 공통 유지·상품별 조정 |
|---|---|---|
| 광원 | ... | ... |
| 그림자 | ... | ... |
| 배경 | ... | ... |
| 배치 | ... | ... |
| 구도 | ... | ... |
| 촬영 각도 | ... | ... |
| 원근감 | ... | ... |
| 초점·심도 | ... | ... |
| 재질 표현 | ... | ... |
| 반사·하이라이트 | ... | ... |
| 색채 설계 | ... | ... |
| 소품·받침대 | ... | ... |
| 상품 상태 | ... | ... |
| 보정·마감 | ... | ... |

안전 영역 대응: {핵심 특징, 상단·하단 UI, 정사각형 잘림, 확대 여유}
판매 구성품과 소품 구분: {구분 방식}
```

선택을 요청할 때는 A·B·C 중 하나와 수정할 요소를 받는다. 사용자가 여러 안의 요소를
조합하고 싶다면 충돌 여부를 설명하고 하나의 승인 가능한 연출안으로 다시 정리한다.
